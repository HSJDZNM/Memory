#  ![OWASPHeader](https://cheatsheetseries.owasp.org/assets/Preface_Cheatsheet_Header.png)
![ProjectLogoOfficial](https://cheatsheetseries.owasp.org/assets/Preface_Cheatsheet_Logo.png)
The **OWASP Cheat Sheet Series** was created to provide a concise collection of high value information on specific application security topics. These cheat sheets were created by various application security professionals who have expertise in specific topics.
We hope that this project provides you with excellent security guidance in an easy to read format. ![😄](https://cdn.jsdelivr.net/gh/jdecked/twemoji@16.0.1/assets/svg/1f604.svg)
You can download this site [here](https://cheatsheetseries.owasp.org/bundle.zip).
An ATOM feed is available [here](https://cheatsheetseries.owasp.org/News.xml) with the latest updates.
