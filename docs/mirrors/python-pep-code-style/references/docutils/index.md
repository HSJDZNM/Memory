# Docutils: Documentation Utilities

Written in Python, for General- and Special-Purpose Use

Docutils is an open-source text processing system for processing plaintext documentation into useful formats, such as HTML, LaTeX, man-pages, OpenDocument, or XML. It includes [reStructuredText](https://docutils.sourceforge.io/rst.html), the easy to read, easy to use, what-you-see-is-what-you-get plaintext markup language.

## Overview

**To get up & running quickly**, see the [Quick-Start](https://docutils.sourceforge.io/README.html#quick-start) section of the [README](https://docutils.sourceforge.io/README.html) file. The only [requirement](https://docutils.sourceforge.io/README.html#dependencies) for running Docutils is [Python](https://www.python.org/).

All **documentation** can be reached from the [Project Documentation Overview](https://docutils.sourceforge.io/docs/index.html). If something is unclear or missing, ask at the [docutils-users](https://docutils.sourceforge.io/docs/user/mailing-lists.html#docutils-users) mailing list.

The SourceForge [project page](https://sourceforge.net/p/docutils) has links to the tracker, mailing lists, and code repository.

All **discussion** about Docutils takes place on the [mailing lists](https://docutils.sourceforge.io/docs/user/mailing-lists.html).

To the developers of an open source project, **feedback** is a great motivator and is very welcome. We also rely on feedback for determining what features to implement. Thus, if you tell us what you need, we may help! Please post any feedback to the [docutils-users](https://docutils.sourceforge.io/docs/user/mailing-lists.html#docutils-users) mailing list.

If you find a **bug** , please [file a bug report](https://docutils.sourceforge.io/BUGS.html#how-to-report-a-bug) or mail to the [docutils-users](https://docutils.sourceforge.io/docs/user/mailing-lists.html#docutils-users) mailing list.

We welcome all kinds of **contributions**. There's a [To Do list](https://docutils.sourceforge.io/docs/dev/todo.html) full of ideas awaiting a champion. If you have any questions regarding how to extend Docutils, please feel free to ask on the [docutils-develop](https://docutils.sourceforge.io/docs/user/mailing-lists.html#docutils-develop) mailing list. **Patch** submissions should be filed in the [patch tracker](https://sourceforge.net/p/docutils/patches/) (preferred) or sent to [docutils-develop](https://docutils.sourceforge.io/docs/user/mailing-lists.html#docutils-develop).
