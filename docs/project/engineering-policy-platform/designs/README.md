## 可运行原型

[console/](console/README.md) 是与文档转规则提案配套的静态原型，包含 6 个页面。
它只展示数据与流程，不提供生产 HTTP 挂载、规则写入或第二份判定；真实治理动作仍须走
Policy API、验证器和 Phase 4 受控执行链。

## 维护边界

- `os/` 是当前平台操作系统设计的唯一总入口；会议原始记录在 `os/meeting/`。
- `console/` 的 `assets/data.js` 是生成物，修改数据源后运行
  `python docs/project/engineering-policy-platform/designs/console/build_site.py` 重建。
- 设计提案中的“未实现”不能写成阶段已交付；落地后应迁移到相应阶段文档并更新本索引。
