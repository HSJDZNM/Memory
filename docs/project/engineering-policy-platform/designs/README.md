## 维护边界

- 提案里的"未实现"不能写成已交付；落地后应把它移出本目录（转入 00–03 的现状文档），并更新本表。
- 本目录只放**尚未实现**的提案、评估与仍有效的评审；已实现的契约在 00–03，两者不得互相冒充。
- 新增/改动提案时，同步更新本表的状态、影响面与下一步——**状态表是这些提案的唯一索引**。
