仓库所有者裁决撤销「OS / GUI 相关」的全部设计开发，以下内容已从仓库移除，**没有留下代码或界面**：

| 已删除 | 内容 |
| --- | --- |
| `designs/os/` | 「平台操作系统」总体设计：9 个板块、A–H 八条流程、8 个页面、会议原始记录（`meeting/`）、裁决 D1–D15 与五期路线 |
| `designs/console/` | 与文档转规则提案配套的静态操作台原型（6 个 HTML + `build_site.py` + `assets/`） |
| `tests/contract/test_console_design.py` | 操作台原型唯一的守卫（3 条字符串断言，只检查 `assets/app.js`） |

恢复方式：这些文件都曾经提交过，`git checkout <commit> -- <path>` 可以取回；本节保留记录是为了让
"提案里引用了原型"这类句子不至于指向空路径。上面四篇「文档转规则」提案与分块策略对比**未撤销**——
它们描述的是内容链路（台阶 1–7）而不是界面，属于提案而非已实现功能。

## 维护边界

- 设计提案中的"未实现"不能写成阶段已交付；落地后应迁移到相应阶段文档并更新本索引。
- 本目录只放提案；已实现的阶段契约在 `../phases/`，两者不得互相冒充。
