| O9 | **AI 辅助起草的合规义务**（如 EU AI Act Art.14 的适用性） | 提案文档提到但**未独立核实** | 法务或合规方的书面判断 | 仓库所有者 | 不做 AI 起草则可忽略；一旦引入即为外部义务 |

## 5. 一页速查：命令 → 它到底回答什么

| 命令 | 回答的问题 | 不回答 |
| --- | --- | --- |
| `python -m policy.check --check-rules` | 规则集能否**整批**加载、身份是什么 | 规则对不对 |
| `python -m policy.check <file> --layer <l>` | 这一次变更的结论与理由 | 其他文件、其他维度 |
| `python -m retrieval.cli verify` | 语料与镜像哈希是否一致 | 检索质量 |
| `python -m retrieval.cli index --check` | 索引要不要重建 | 索引是否可信 |
| `python -m validators.cli registry` / `probe` | 谁能产证据、外部工具在不在 | 这次改动合不合规 |
| `python -m enforcement.cli registry --verify` | 工具表是否与已审核哈希一致 | 某个动作能不能做 |
| `python -m enforcement.cli precheck …` | 这个动作+参数能不能过门禁 | 副作用是否已发生 |
| `python -m policy_api.cli self-check` | 装配、就绪、契约是否一致 | 业务结论 |
| `python -m policy_api.cli openapi --check` | 传输契约是否漂移 | 语义是否兼容 |
| `python -m orchestration.cli self-check` | 图与引擎能否装配 | 允不允许某个动作 |
| `python tools/ci_local.py` | 本机门禁是否全过 | 规则集与上次是否相同（**不是**） |
| `python tools/phase_evidence.py` | 阶段证据能否重建 | 同上；以每次实际运行结果为准 |
